Lab Exercises — What We Build

#ExerciseWhat you do
00Readiness checkVerify VS Code, extensions, Python, devtunnel, and that SQL Hyperscale + FAQ tables are ready.
01Schema + embeddingsCreate the FAQ schema, seed content, generate vector embeddings, and build dbo.SearchFAQ.
02Copilot semantic searchUse GitHub Copilot to write T-SQL comparing keyword vs semantic (vector) search.
03RAG → gpt-5Build a grounded prompt from top FAQ matches and call gpt-5 for the final answer.
04Foundry agent + MCPExpose SQL via an MCP server over a dev tunnel; orchestrate retrieval with a Foundry Agent.
05Microsoft FabricMirror SQL data to OneLake and build a Power BI report over Direct Lake.
